# Contributing to Simple Interest Calculator

Thank you for considering contributing to this project!

## Welcome

All contributions, bug reports, bug fixes, documentation improvements, enhancements, and ideas are welcome.

We value all contributions from the community and want to make it easy for anyone to contribute.

## How to Contribute

1.  Fork the repository
2.  Create a new branch (`git checkout -b feature-branch`)
3.  Make your changes
4.  Commit your changes (`git commit -m 'Add some feature'`)
5.  Push to the branch (`git push origin feature-branch`)
6.  Open a Pull Request

## Types of Contributions We Welcome

*   **Bug reports:** If you find a bug, please create an issue describing the bug, how to reproduce it, and the expected behavior.
*   **Bug fixes:** If you fix a bug, please submit a pull request with a clear description of the fix.
*   **Documentation improvements:** Improvements to README, comments, or other docs are highly appreciated.
*   **Enhancements:** New features or improvements to existing functionality.
*   **Ideas:** Have a new idea? Open an issue to discuss it.

## Code of Conduct

Please note that this project is released with a Contributor Code of Conduct. By participating in this project you agree to abide by its terms. See CODE_OF_CONDUCT.md.

## Questions?

If you have any questions, feel free to open an issue.

Thank you!
